tuples
	-> non-similiar non-changable indexed items together
	-> () is used for tuples
------------------------------------------------------------------------------------
a=(10,20,30,40,50)

print(a)

print(sum(a))
print(min(a))
print(max(a))
print(a.index(20))

set
	-> non-similiar non-indexed elements together
	-> {} is used for set
	-> remove duplicate entries automatically
----------------------------------------------------------------------------------
a={10,20,30,40,50,10}

print(a)

#print(a[2])    non-indexed

print(min(a))
print(max(a))
print(sum(a))

dictionary
	-> maintain key and value pair
	-> key should be unique and value can be duplicate
	-> {} is used for dictionary
-----------------------------------------------------------------------------------------
emp={'111':'ashok','222':'suresh','444':'vineet','222':'lalit','555':'ashok'}

print(emp)
print(emp.keys())
print(emp.values())
print(emp.items())
